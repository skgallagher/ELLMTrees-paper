\section{Framework}
\label{sec:framework}
% -----------------------------------------------------------------------

In this section, we define our terms and notation and establish the statistical framework underlying our experiments.


Much like \citep{wu2026llmdna}, we use the framework of phylogenies and LLM ``DNA'' to estimate important properties of parent-child training. We assume, unlike \cite{} but like \citep{yu2025neural}, that all node models are derived from a single root model. Unlike prior works, we focus not only on parent-child pairs but on recovering partial topology across all nodes, not just child-parent pairs.  We estimate the phylogeny by first estimating a distance matrix and then using neighbor-joining \citep{saitou1987neighbor} to recover the training tree.


\subsection{Phylogenetic Tree Recovery}
\label{sec:framework:phylo}
% We frame fine-tuning lineage recovery as a phylogenetics problem.
% Pairwise weight distances → NJ tree → RF vs ground truth → permutation p.
% Why NJ > directed MST (MoTHer): statistically principled, known properties.
% Cite: Saitou & Nei 1987 (NJ), Robinson & Foulds 1981 (RF).

To estimate $\widehat{\mathcal{P}}$, we use the following recipe:

\begin{enumerate}
    \item Choose set of layers $\mathcal{L}$ and distance (or similarity) metric ($d$)
    \item For layer $L^{(\ell)}$, estimate the distance between the layer weights from model $i$ to model $j$,
    $$
    D_{i,j}^{(\ell)} = d(L^{(\ell)}_i, L^{(\ell)}_j)
    $$
    \item Assemble $\hat{\textbf{D}}$, where $\hat{\textbf{D}}$ is function of the $D_{i,j}^{(\ell)}$ distances such as the average distance of pairwise weights across all layers
    \item Estimate $\widehat{{\mathcal{P}}}$ using $f(\hat{\textbf{D}})$ where $f$ is the NJ method\footnote{We assume that the models in question are leaves and not internal nodes}
\end{enumerate}

Step (3) allows us to use different layers to achieve different or even multiple estimates of $\widehat{\mathcal{P}}$, which we can do to evaluate layer importance.  Since phylogeny-space grows super-exponentially in the number of leaves, exact topology recovery is unlikely.
Instead, researchers commonly use Robinson-Foulds (RF) distance \citep{robinson1981comparison} to measure how ``close'' an estimated phylogeny is to the true one, a measure of partial topology recovery. An RF distance of $k$ means the two trees disagree on $k$ bipartitions, splits present in one tree but absent in the other.
A maximum RF distance can be computed from the total number of leaves, and the ratio (normalized RF) enables comparison across trees of different sizes. A normalized RF near 0 indicates near-perfect recovery; near 1 indicates a tree no better than random.

We assess significance via a permutation test. Let $\mathrm{RF}(\widehat{\mathcal{P}},
\mathcal{P}^*)$ denote the Robinson-Foulds distance between the estimated and
ground-truth trees for a given run. The null hypothesis is that $\widehat{\mathcal{P}}$
carries no lineage information:
$$
H_0: \mathrm{RF}(\widehat{\mathcal{P}}, \mathcal{P}^*) \ge
     \mathrm{RF}(\mathcal{P}_{\text{rand}}, \mathcal{P}^*)
$$
where $\mathcal{P}_{\text{rand}}$ is drawn uniformly from the space of binary trees
on $n$ leaves. We approximate this null distribution with 1{,}000 random trees per
run, yielding a permutation $p$-value for each run. To combine evidence across the
50 independent runs, we apply Fisher's method: $-2\sum_{i=1}^{50} \log p_i \sim
\chi^2(100)$ under the global null.

\subsection{Distance Metric: Cosine and the SNR Argument}
\label{sec:framework:metric}

One question we sought to answer is what distance (or similarity) metric should we use to compare layers of weights to one another.  We decided to use vector-based norms as opposed to matrix or array based norms for easier portability across architectures.  The distances we considered are  cosine, correlation, $\ell_1$ and $\ell_2$ (the latter of which was used in MoTHER \cite{}).  The first two distances are bounded by 1 and so the distances are comparable across different layers.  The second two distances are unbounded, which can allow different magnitudes of weights to dominate the distance.

To determine which metric to use, we use within-run Signal to Noise Ratio (SNR), $\mathbb{E}[X]^2/\mathrm{Var}[X]$, as a heuristic with the intuition that a larger SNR will lead to easier separation among distances and thus better phylogenies.  The results of this experiment are shown in Table~\ref{tab:metric-snr}.

One result we see in Table~\ref{tab:metric-snr} is that cosine distance and correlation generally have the highest SNR across our different experiments.  Intuitively, this makes sense because the larger magnitude layers such as layer norms which are known to be noisy \cite{} have less chance to dominate.  Thus, we see that scaling the distance within layers is important.  For the rest of the analysis, we choose cosine similarity over correlation because we view them as largely as comparable with cosine distance having more prominence in layer weight analyses \cite{}.

\subsection{Per Layer Estimated Phylogenies}
\label{sec:framework:layers}
% Each weight tensor → its own NJ tree.
% Distribution of per-layer RF distances is the data; consensus tree is summary.
% More statistically principled than any competitor — flag explicitly.

One contribution we have in our methodology is the use of per-layer distance matrices between models as independent estimates as opposed to using the total distance across all layers.  The inspiration for this analysis is how biological phylogenies are estimated across multiple genes, the assumption being that different genes encode different information on how changes are occurring \cite{}.

Thus, a model with $L$ layers can result in $L$ distance matrices.  These distance matrices can either be used to each form their own estimate of $\hat{P}$ resulting in a collection of estimates.  From that set, a conensus phylogeny (i.e. the most common tree) is generally taken as the estimate.  Another alternative is to use a function of the distance matrices, such as the mean, to have a less noisy estimate of $\hat{\textbf{D}}$, to form $\widehat{\mathcal{P}}$. In addition to giving us a less variable estimate of the phylogeny, this layer-wise distance allows us to identify the most and least important layers in training by examining which layers change the most or least across multiple training runs.

\section{Experiments}
\label{sec:experiments}
% -----------------------------------------------------------------------
We structure our experiments around three questions: whether weight changes
recover training lineage, whether they predict downstream behavior, and
whether family structure is visible from behavioral outputs alone in
frontier models without weight access.

\subsection{Controlled Branching Trees}
\label{sec:exp:trees}
% Base: Flan-T5-base (250M). Bernoulli branching, 4 tasks, 50 replications,
% 5--8 leaves, known topology by construction.
% 2000 steps, lr=3e-4, batch=8, grad_accum=4, bf16.
% Controlled design enables RF evaluation — all competitors lack this.

To create a controlled experiment, we generate stochastic phylogenies or training trees, beginning from a root model.  The tree generating process is described in detail in Appenidx \ref{app:details}.  Our generating process produces fairly balanced phylogenies with up to 8 leaf nodes.  We generate 50 such phylogenies, each constituting the basic structure for a single training tree. We then assign task/dataset pairs to each edge. At each split in the tree, a child model is fine-tuned from its parent model on a random task/data set pair.  First a training task is randomly sampled and then a dataset within that task is randomly sampled.  The resulting pair is assigned to that edge.

%% This probably gets moved to intro or somewhere -- it's a real scenario
The motivation for this controlled experiment is from an industry-type training where a base model is given to different departments and each department is able to perform its own fine tuning on a model.  A question may arise if a new department begins and is interested in using an already fine-tuned model on a new task.  Which one should they pick?

The generated phylogenies are then used as fine-tuning instructions, the details of which can be found in Appendix [add-fine-tuning-instructions].  At each node in the phylogeny, a new model is trained and we can access each \textit{leaf} model's weights. 

\subsection{Do weight changes carry model lineage?}
\label{sec:exp:weights}

Once we have the trained leaf models, we can use the steps in Section \ref{sec:framework:phylo} to estimate a phylogeny from the weight changes.  Since we know the actual training trees, we then can use RF distance to compare how far the estimated phylogeny is from the known training tree, unlike previous works.  We repeat this process for each generated phylogeny.

In our experiments, we vary the root model, task types, and which layers we train. We examine both an encoder-decoder model and a decoder-only model: Flan-T5-base (250M parameters) and Llama-3.1-8B, respectively. The tasks we fine-tune on include Q\&A, classification, translation, and text summarization. For Flan-T5-base, we run both full fine-tuning and four LoRA \citep{hu2022lora} adapter configurations varying the scope of trained parameters: key projection matrices only, query/key/value projections, all four attention projections (including output), and all projection matrices. Llama-3.1-8B serves as both a decoder-only and entry into more frontier-like models.  Llama-3.1-8B is trained with the key-only and query/key/value LoRA configurations; full fine-tuning is omitted at this scale due to memory constraints. Detailed training hyperparameters for all conditions are in Appendix~\ref{app:details}.

%\subsubsection{Geometric Mechanism: Task Subspaces}
%\label{sec:exp:geometry}
% Displacement subspace angles between fine-tuning directions.
% Cross-task grand mean ~84 degrees (near-orthogonal).
% Within-task 80.7--86.0 degrees — dose-response confirmed.
% RTE forgetting probe: classification vs RTE = 64.8 degrees.
% Cite: Ilharco et al. 2023 (Task Arithmetic) for task vectors.

To understand geometrically \textit{why} fine-tuning ancestry is recoverable from
weights, we measure the directions in which different training runs displace a model
from its starting point. For each fine-tuned checkpoint, we compute the weight
displacement $\Delta W = W_{\text{fine-tuned}} - W_{\text{base}}$, which captures
the net effect of all gradient updates relative to the pre-trained initialization.
We then measure the principal angles between the subspaces spanned by these
displacement vectors for pairs of fine-tuned models \citep{ilharco2023editing}.
Near-$90^\circ$ angles indicate that two training runs push the model into nearly
orthogonal regions of weight space; smaller angles indicate overlap.

We investigate three questions with this analysis. First, do different task types
induce near-orthogonal displacement directions. Second, does within-task training (same task type, different datasets) produce less orthogonal displacements than cross-task training? Third, does
LoRA's low-rank constraint alter the \textit{direction} of weight updates, or
does it primarily reduce their magnitude? We apply the subspace angle analysis
both globally (pooling all weight matrices) and per-layer, which can identify if certain layers are more variable in task/data set fine-tuning process.


\subsection{Can Weight Changes Predict Behavior?}
\label{sec:exp:behavioral}

While recovering ancestral information about a model is important for
provenance and auditing, a practical question is whether weight-space
proximity predicts anything useful about model behavior. Here we test
whether whitebox weight distance is a significant predictor of behavioral
similarity on a probe task, after controlling for run-level variation.

We operationalize behavioral similarity in two ways: task performance
(ROUGE-L) and semantic similarity between model outputs measured via
sentence-embedding cosine distance, with the latter as our primary
dependent variable. In both cases we fit a mixed-effects regression with
weight distance as the key predictor and run as a random interceptWe assess significance via a permutation test. Let $\mathrm{RF}(\widehat{\mathcal{P}},
\mathcal{P}^*)$ denote the Robinson-Foulds distance between the estimated and
ground-truth trees for a given run. The null hypothesis is that $\widehat{\mathcal{P}}$
carries no lineage information --- formally, that the observed RF is no smaller than
what would be obtained from a uniformly random binary tree with the same leaf count:
$$
H_0: \mathrm{RF}(\widehat{\mathcal{P}}, \mathcal{P}^*) \ge
     \mathrm{RF}(\mathcal{P}_{\text{rand}}, \mathcal{P}^*)
$$
where $\mathcal{P}_{\text{rand}}$ is drawn uniformly from the space of binary trees
on $n$ leaves. We approximate this null distribution with 1{,}000 random trees per
run, yielding a permutation $p$-value for each run. To combine evidence across the
50 independent runs, we apply Fisher's method: $-2\sum_{i=1}^{50} \log p_i \sim
\chi^2(100)$ under the global null.
(see Appendix~\ref{app:regression} for full model specifications and
sensitivity analyses).

For Flan-T5-base, we use translation as the probe task, training models
on summarization, QA, and classification only and withholding translation
as the holdout. For Llama-3.1-8B, we use HellaSwag --- a commonsense
sentence-completion benchmark --- as the held-out probe. The probes differ
across architectures because Flan-T5-base lacks the base commonsense
ability required for HellaSwag, producing degenerate outputs regardless
of fine-tuning condition (see Appendix~\ref{app:translation_probe}).
Llama-3.1-8B, by contrast, retains strong commonsense ability after
LoRA fine-tuning, making HellaSwag a meaningful held-out test of whether
weight proximity predicts behavioral similarity beyond the training
distribution.

\subsection{Behavior from Blackbox, Frontier Models}
\label{sec:exp:blackbox}
% GPT, Claude, Gemini, Llama probed via output embeddings across 4 tasks.
% Family structure recoverable when aggregating tasks.
% Single-task confounded by formatting (verbosity, markdown).
% Translation cleanest — language crossing decouples embedding from source content.

Sometimes model weights are unavailable, and provenance must be inferred from behavioral outputs alone. Recent work has shown that frontier model families cluster meaningfully in behavioral embedding space
\citep{wu2026llmdna, grayson2024phylolm}. We extend this line of work by probing 16 frontier models (GPT, Claude, Gemini, and open-weight families including Llama and Mistral) across four task types --- summarization, QA, classification, and translation --- using the same neighbor joining pipeline applied to pairwise sentence-embedding distances between model outputs. This design allows us to examine how much the recovered family structure depends
on task choice, and whether aggregating across tasks recovers structure that
single-task probes miss.

\section{Experimental Details}
\label{app:details}

\subsection*{Tree Generation}
\label{app:tree-gen}

Training trees are generated via a Poisson branching process as follows:

\begin{enumerate}
    \item The root node (pretrained Flan-T5-base) draws $k \sim \mathrm{Poisson}(\lambda = 1.5)$ children, with a minimum of 1.
    \item Each subsequent node draws $k \sim \mathrm{Poisson}(\lambda = 1.5)$ children. Nodes that draw $k = 0$ naturally become leaves --- no separate pruning step is needed.
    \item Breadth First Search expansion continues until either a node budget ($n_\mathrm{nodes} = 14$ training nodes, not counting the root) is exhausted or a maximum depth ($n_\mathrm{layers} = 4$) is reached. The budget cap creates the truncation; any node alive when the budget runs out becomes a leaf.
    \item Each non-root node is assigned a task and dataset sampled without replacement from 4 task types (summarization, classification, QA, translation) and 36 datasets (9 summarization, 10 classification, 8 QA, 9 translation). The topology (parent--child structure) is fixed by a topology seed; dataset assignments vary across the 50 replications.
    \item Runs with fewer than 4 leaves are excluded from analysis, as trees with 3 or fewer leaves have trivial topology with no meaningful RF distance.
\end{enumerate}

This procedure yields trees with 4--8 observed leaves across the 50 replications, with variable depth and branching structure. The ground-truth topology is fully known by construction, enabling exact RF evaluation.

\subsection*{Training Configuration}
Base model: Flan-T5-base (250M parameters). Each node trained for 2,000 steps, learning rate $3 \times 10^{-4}$, batch size 8, gradient accumulation 4 (effective batch 32), warmup 200 steps, weight decay 0.01, bf16 precision. Up to 10,000 training examples and 1,000 evaluation examples per dataset, fixed dataset seed across all nodes to avoid data variation as a confound.

\section{Behavioral Regression: Full Results}
\label{app:regression}

All models regress behavioral output similarity (sentence-embedding cosine, translation probe
unless noted) on cosine weight distance with run fixed effects and SEs clustered on run. We report
three coefficients per condition (Table~\ref{tab:regression_betas}):
\begin{itemize}
  \item \textbf{Raw $\beta$} --- the unscaled slope. Significant and negative everywhere, but
    \emph{not} comparable across conditions: LoRA groups have far smaller absolute cosine distances,
    so their raw $\beta$ is inflated by orders of magnitude (e.g.\ $-52$ for full\_ft\_approx vs.\
    $-0.19$ for k\_only) without implying a larger effect.
  \item \textbf{Semi-standardized $\beta$} --- predictor $z$-scored within run; reads as ``$\Delta$
    output similarity per 1 within-run SD of weight distance.'' Interpretable within a condition,
    but still not cross-comparable because conditions differ in how much their \emph{outputs} vary
    (k\_only translations are near-identical, so its semi-standardized $\beta$ is tiny despite the
    strongest correlation).
  \item \textbf{Standardized $\beta$ (within-run)} --- both sides $z$-scored within run. This is the
    only cross-condition-comparable effect size, and it equals the within-run correlation. It is the
    number reported in the main text.
\end{itemize}

\section{Decoder-Only at Scale: Llama and the Search for a Recovering Rank}
\label{app:llama}

We include decoder-only Llama models (3.1-8B, 3.2-1B-Instruct) as a robustness check at frontier
scale. All groups are cloned from the \texttt{branching\_v3} topologies (identical trees, so RF is
directly comparable to Table~\ref{tab:rf_by_leaves}) and fine-tuned with LoRA at rank $r=8$;
analysis uses \textsc{trained\_only=1} and \texttt{--min-leaves 4}.

The headline is a \emph{dissociation}: the pairwise ordering signal survives the
encoder-decoder$\rightarrow$decoder-only switch, but full topology recovery does not.
Table~\ref{tab:llama_recovery} shows every Llama group beats the random null on the ordering test
(rank-biserial $r\approx0.20$--$0.25$, all Mann-Whitney $p<10^{-6}$), yet clade recovery sits at
$20$--$32\%$ and \emph{no} group ever beats the label permutation ($0\%$ significant
vs.\ label)---i.e.\ it recovers task-level clustering, not within-task lineage. Contrast the
encoder-decoder Flan-T5 full FT ($\approx90\%$ clade recovery, Table~\ref{tab:rf_by_leaves}) and
Flan LoRA qkv ($\approx83\%$).

The mechanism is dimensional dilution: at fixed rank, the weight update occupies a vanishing
fraction of the ambient space, so per-matrix updates become near-orthogonal (qkv cosine distance
mean $0.943$, jammed at the ceiling) and the metric geometry that NJ needs collapses, even as the
\emph{rank order} of distances stays informative. This makes $s=r/d$, not decoder-ness per se, the
controlling variable: halving $d$ from 8B to 1B (doubling $s$) lifts clade recovery from
$\sim$20\% to $\sim$30\%. Accordingly we use the Llama family not as a recovery result but as a
probe for the rank $r$ at which recovery returns. We are running a qkv rank sweep on
Llama-3.2-1B-Instruct ($r\in\{2,4,8,16,32\}$, i.e.\ $s$ from $1.0\!\times\!10^{-3}$ to
$1.6\!\times\!10^{-2}$, spanning Flan's $\approx1.0\!\times\!10^{-2}$); the prediction is that
clade recovery and \%-sig-vs-label cross zero near the Flan operating point. \TODO{Add the

\section{Translation Probe Outputs for TaskHoldout Models}
\label{app:translation_probe}

the translation probe to test whether weight distance predicts behavioral similarity
even when the probe task was never trained. However, this condition reveals a
fundamental limitation of behavioral probing on out-of-distribution tasks: models
whose most recent fine-tuning was on classification have overwritten the base
model's translation ability entirely, producing degenerate single-token outputs
rather than translations.
