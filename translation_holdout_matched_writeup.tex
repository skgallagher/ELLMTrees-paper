% Main-text methods paragraph
For the Llama translation-held-out condition, we use a matched intervention on
the same 50 training-tree topologies as the full-fine-tuning condition. We hold
the base model, trainer, stopping rule, topology, node order, and every original
non-translation task--dataset assignment fixed. Of the 641 training nodes, 479
retain their original assignments exactly. The remaining 162 nodes are precisely
those originally assigned a translation dataset; we replace each of these,
without replacement within its tree, with an otherwise unused summarization,
classification, or question-answering dataset. Replacement draws are
deterministic within tree from the original assignment seed. Thus no node in the
matched condition trains on translation, while the tree structure and all
non-translation training interventions remain unchanged. We then evaluate the
retained leaf models on translation using the same three-draw paired semantic
similarity and random-effects $r_{\mathrm{DL}}$ pipeline as the other behavioral
probes.

% Appendix provenance and audit paragraph
The matched assignment derivation starts from the accepted production manifests
and compares each derived runner row against its production counterpart. The
audit requires identical tree id, node id, parent id, depth, root-to-node path,
trainer configuration, base-model revision, and fine-tuning method. A row may
change task family or dataset only if its production task family was
\texttt{translation}. Within every tree, replacement datasets must remain unique,
and the final manifests must contain no translation assignment. Before launch,
the independent runner audit found 50/50 identical topologies, 479/479 preserved
non-translation rows, 162/162 translation-only replacements, zero other row
changes, zero duplicate datasets, and zero overlapping output directories. The
production array uses one L40, four CPUs, and 64~GB per tree with an eight-task
concurrency cap.
